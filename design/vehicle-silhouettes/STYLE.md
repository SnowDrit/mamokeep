# Стиль силуэтов транспорта

- Исходники — SVG с прозрачным фоном, без логотипов и модельных особенностей.
- Основной контур: чёрный, скруглённые концы и соединения, базовая толщина `2.4` при `viewBox="0 0 160 80"`.
- У дорожных автомобилей один рисунок диска: пять спиц, внутренняя окружность и компактная ступица. Переднее и заднее колёса используют одну геометрию без случайных вариаций.
- Плечевая линия кузова под боковым зеркалом остаётся прямой. Зеркало рисуется отдельным контуром и не деформируется этой линией.
- Двухсекционная вертикальная решётка используется только в ракурсах, где машина повёрнута передком к зрителю. Строгие боковые силуэты остаются без неё. Форма оригинальная, без эмблемы и без точного повторения конкретной марки.
- В ракурсах 3/4 допускается перспективное сжатие колеса, но порядок и число спиц не меняются.
- Мастер-файлы — SVG с настоящими кривыми, полученными из утверждённых детальных рисунков через VTracer. Светлый фон удаляется после трассировки фильтром яркости, поэтому он остаётся прозрачным при любом масштабе.
- Android не загружает обычный SVG через `painterResource`, поэтому приложение использует его полноразмерную прозрачную PNG-копию из `drawable-nodpi`. Это тот же рисунок без упрощённой ручной перерисовки; цвет линий по-прежнему задаёт Compose.
- У каждого из десяти легковых кузовов есть два рабочих мастер-файла: профиль вправо для выбора и малых заголовков, а также передний ракурс 3/4 с оригинальной решёткой для большой карточки гаража.
- Полный набор: седан, хэтчбек, лифтбек, универсал, кроссовер, SUV, купе, кабриолет, пикап и минивэн. Их масштаб нормализован общим конвертером `process_vehicle_art.py`.
- Коммерческий набор построен по той же схеме и также имеет отдельные профиль и ракурс 3/4: фургон, микроавтобус, автобус, бортовой грузовик, тягач, самосвал, автоцистерна и эвакуатор.
- У коммерческих профилей сохранены различимые рабочие признаки: окна у микроавтобуса, пассажирские двери у автобуса, открытое седло у тягача, кузов самосвала, цилиндрическая цистерна и пустая наклонная платформа эвакуатора.
- Двухколёсный набор включает дорожный мотоцикл с открытой рамой и городской скутер со сквозной посадкой. Для каждого используются профиль вправо и передний ракурс 3/4 без водителя.
- Набор «Прочее» завершает каталог: квадроцикл, снегоход, самоходный дом на колёсах, отдельный прицеп-дача и сельскохозяйственный трактор без навесного оборудования. Все пять также имеют профиль и отдельный ракурс 3/4.
- Для кроссовера дополнительно сохранены профиль влево и ранний ракурс 3/4 без решётки как материалы сравнения; приложение их не использует.
